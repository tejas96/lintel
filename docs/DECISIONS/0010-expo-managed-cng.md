# 0010 — Expo SDK 58, managed workflow with continuous native generation

**Decision.** One React Native codebase (Expo SDK 58, React Native 0.88, expo-router)
for iOS and Android. `ios/` and `android/` are generated by prebuild and not
committed; native configuration lives in `app.config.ts` and config plugins.

**Consequences.** No duplicated platform code; upgrades follow Expo SDK releases.
Push on iOS through FCM requires adding the Firebase iOS SDK
(`@react-native-firebase/messaging`), `GoogleService-Info.plist` and an APNs key —
documented in `docs/INTEGRATIONS.md` and `apps/mobile/README.md`.
